Memory Architecture
Sessions & Facts
Sessions are full conversation transcripts. Facts are small durable items like identity, preferences, and constraints extracted or saved explicitly for fast retrieval.
Working & Episodic
Working memory tracks active task context by topic cluster while work is ongoing. Episodic memory stores short "what happened" summaries for completed or notable sessions.
Compacted & Procedural
Compacted memory holds cluster-level summaries used for semantic cache and enrichment. Procedural memory stores reusable how-to patterns distilled from repeated successful work.
Insights
Insights are cross-session observations generated by the daemon — recurring themes, preferences, and higher-level patterns learned over time.

Memory Compression

Compress & Archive

Reads all saved sessions, calls Ollama in map-reduce fashion, and produces a single structured memory document covering who you are, your working style, active projects, key decisions, and recurring patterns. All source sessions are deleted — the compressed document becomes the new memory baseline. Also written to ~/.memory/compressed_memory.md. The daemon runs this automatically every 50 sessions.

Ollama must be running.
