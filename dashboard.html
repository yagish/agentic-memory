Memory API is the service formerly shown as “Recall Server.” It serves retrieval requests and warms the local embedding model used for semantic lookup. The Process One Session button asks the daemon pipeline to pick the next unprocessed session and run one extraction pass immediately. Savings metrics are approximate and come from direct memory-answer hits logged in ~/.memory/activity.log using a rough chars / 4 heuristic. Click any memory count tile to jump to that table, or click any row in a memory table to inspect full details below it.
